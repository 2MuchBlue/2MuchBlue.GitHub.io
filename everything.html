Tools I Use

I have used a few different game engines: Scratch; Tic80; Vanilla JavaScript; and recently I've been using Unity 2020 (I know I should learn something else like Godot).
For pixel art, I use GIMP, specifically the 2.10.38 version. I have no idea why I use such a specific version. (FYI, GIMP is basically an open source photoshop.)
I haven't used it in a game yet, but I am familiar with Inkscape, basically an open source Adobe Illistrator.
Most all my 3D stuffs is handeled in Blender. For a while Unity would only import from Blender 2.7-ish, at some point that was fixed, so I have been getting aquainted with the new versions!
For music, I tend to use BeepBox or one of the many offshoots for music. I have also been trying to use Milky Tracker. I haven't published anything with it but I am playing with it!
